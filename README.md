# Py-Marina-uppgift6
Bygger filmsida med react där man kan lägga till en film och betgsätta den. 

Sedan kan man sortera dessa enligt alabetisk ordning eller efter betyg. 

## Tech Stack
- React
- Vite


## bash
Starta projektet genom att skriva:  
# Py-Marina-uppgift6
Bygger filmsida med react där man kan lägga till en film och betgsätta dem. 

Filmerna kan sorteras: 
- i alfabetisk ordning
- efter betyg

## Tech Stack
- React
- Vite


## Starta projektet
Starta projektet genom att skriva i terminalen:  

- npm install 
- npm run 

Tryck sedan på länken som visas i terminalen för att öppnna hemsidan.
